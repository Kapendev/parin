# Rin

A script interpreter for Rin.
It helps with error checking and debugging.
Text lines are printed, and menu lines ask for an option number in the terminal.

## Usage

* With DUB: `dub run parin:rin`
* Without DUB: `dmd -I=parin_path/source -i -run source/app.d script.rin`

Run it without a script to see the options.
Example scripts are in the examples folder.

## Editor Themes

Rin syntax highlighting files for various text editors are available in the [assets](./assets/) folder.
